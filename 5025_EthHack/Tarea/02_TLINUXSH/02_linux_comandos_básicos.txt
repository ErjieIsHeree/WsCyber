Comandos Básicos en Linux
Comando cat (enlace al manual)
¿Qué hace?
Muestra el contenido de un archivo por pantalla.

Uso básico:

cat archivo.txt


Parámetros comunes:

-n: Numera las líneas del archivo.


-E: Muestra el carácter $ al final de cada línea.


Ejemplo:

cat -n ejemplo.txt


¿Para qué sirve?

Ver el contenido de archivos.


Concatenar archivos:


cat archivo1.txt archivo2.txt


Acceder a archivos con espacios en el nombre:

Usando comillas:


cat "mi archivo con espacios.txt"


Usando caracteres de escape:


cat mi\ archivo\ con\ espacios.txt



Comando grep (enlace al manual)
¿Qué hace?
Busca texto dentro de archivos o salidas de comandos.

Uso básico:

grep "palabra" archivo.txt


Parámetros comunes:

-i: Ignora mayúsculas/minúsculas.


-r: Busca recursivamente.


-n: Muestra número de línea.


--color: Resalta coincidencias.


Ejemplo:

grep -i "error" logs.txt



Comando strings (enlace al manual)
¿Qué hace?
Extrae cadenas legibles de archivos binarios.

Uso básico:

strings archivo.bin


Ejemplo:

strings programa.exe | grep "clave"


¿Para qué sirve?

Ver texto legible en ejecutables.


Extraer información sospechosa de binarios.



Comando uniq (enlace al manual)
¿Qué hace?
Elimina líneas consecutivas duplicadas.

Uso básico:

uniq archivo.txt


Parámetros comunes:

-c: Cuenta ocurrencias.


-d: Solo duplicadas.


-u: Solo únicas.


Ejemplo:

sort archivo.txt | uniq -c



Comando find (enlace al manual)
¿Qué hace?
Busca archivos y directorios según criterios.

Uso básico:

find /ruta -name "archivo.txt"


Parámetros comunes:

-name: Busca por nombre.


-type f: Solo archivos.


-type d: Solo directorios.


-size: Busca por tamaño.


-user: Busca por propietario.


-exec: Ejecuta comandos sobre los resultados.


Ejemplos:

find . -size +10M

find /var/log -user juan

find /home -type f -user maria -size -2M -name "*.txt"

find . -name "*.tmp" -exec rm {} \;



Comando sort (enlace al manual)
¿Qué hace?
Ordena líneas de texto.

Uso básico:

sort archivo.txt


Parámetros comunes:

-r: Orden inverso.


-n: Orden numérico.


-u: Elimina duplicados.


-k: Ordena por columna.


Ejemplos:

sort -n notas.txt

sort -k2 empleados.txt



 Operadores de redirección y tuberías
| (pipe)
Conecta la salida de un comando con la entrada de otro:

cat archivo.txt | grep "error"


> (redirección de salida)
Guarda la salida en un archivo (sobrescribe):

ls > listado.txt


>> (redirección de salida con añadido)
Añade la salida al final de un archivo:

echo "nueva línea" >> archivo.txt


< (redirección de entrada)
Toma un archivo como entrada de un comando:

sort < datos.txt




Comando more (manpage)
¿Qué hace?
Muestra contenido de archivos página a página, ideal para visualizar archivos largos.

Uso básico:

more archivo.txt


Controles durante la ejecución:

Espacio → Página siguiente


Enter → Línea siguiente


b → Página anterior


q → Salir


/palabra → Buscar palabra


n → Siguiente ocurrencia


Ejemplo:

more /var/log/syslog


Ejecutar un editor desde more
Una característica poco conocida pero útil es que desde more, al pulsar la tecla v, se lanza un editor (habitualmente vi) con el archivo actual.

Esto permite modificar el archivo directamente desde la vista de solo lectura, algo especialmente valioso en contextos donde no hay una sesión interactiva completa disponible. Quien domine el editor abierto sabrá cómo usarlo para localizar o incluso editar otros archivos desde allí mismo.


Comando file (manpage)
¿Qué hace?
Identifica el tipo de archivo, examinando su contenido en lugar de la extensión.

Uso básico:

file nombre_archivo


Ejemplos:

file imagen.jpg

file script.sh

file archivo_sospechoso


Esto es especialmente útil cuando recibimos archivos sin extensión o cuando sospechamos que el contenido no coincide con el nombre.

Salida típica:

ASCII text


JPEG image data


ELF 64-bit LSB executable


gzip compressed data


Combinación útil:

file * | grep "executable"


Permite localizar ejecutables en un directorio.



Comando tr (manpage)
Función Traduce, suprime o comprime caracteres.

Forma: tr [OPCIONES] SET1 [SET2]

-d eliminar

-s comprimir repeticiones

-c complementar SET1.


Ejemplo:

echo "123abc" | tr -d '0-9'    # → abc

Aplicación destacada: Puede simular un cifrado César desplazando caracteres:

echo "hola" | tr 'a-z' 'd-za-c'   # "krod"
echo "krod" | tr 'a-z' 'x-za-w'   # "hola"

Esto funciona gracias al mapeo de conjuntos de letras.


Comando base64 (manpage)
Codifica/decodifica en Base‑64.

Codificar: base64 entrada.bin > salida.b64


Decodificar: base64 -d salida.b64 > recuperado.bin



Comando gzip (manpage)
Compresor de un solo archivo.

Comprimir: gzip archivo.log → archivo.log.gz


Descomprimir: gzip -d archivo.log.gz o gunzip archivo.log.gz


Ver tamaño original: gzip -l archivo.log.gz



Comando tar (manpage)
Empaqueta y (opcionalmente) comprime conjuntos de archivos.

Acciones usuales:

Crear: tar -czf backup.tgz /etc


Extraer: tar -xzf backup.tgz -C /tmp/restore


Listar: tar -tzf backup.tgz | less


Opciones clave: -c create · -x extract · -t list · -v verbose · -f fichero destino · -z gzip · -J xz.


Comando xxd (manpage)
Crea/convierte hexdumps.

Dump: xxd archivo.bin | head


Restaurar: xxd -r hexdump.txt > original.bin



Comando ssh (manpage)
Cliente SSH para conexión remota cifrada.

Uso mínimo: ssh usuario@servidor

Conexión mediante clave privada
ssh -i ~/.ssh/id_rsa  profesor@192.168.1.50

-i indica el fichero de clave; si la clave está protegida con passphrase se solicitará al iniciar la sesión.

Ejecutar comandos remotos sin sesión interactiva
ssh user@host ls /var/log

Esto permite automatizar tareas o lanzar scripts desde otro sistema.

Otras opciones frecuentes: -p PUERTO · -L reenvío local · -R remoto · -J jump host.


Comando nc / netcat (manpage)
Herramienta versátil de red; puede actuar como cliente, escáner o servidor.

Crear un servidor TCP sencillo
nc -l -p 8080 -k -v

-l listen (modo servidor)1


-p PORT puerto a escuchar


-k mantener la escucha tras cada conexión


-v salida detallada


Otros parámetros clave
-n no resolver DNS · -u UDP · -z escaneo (no envía datos) · -w SEG timeout · -e PROG ejecuta PROG al conectar (desaconsejado por seguridad)

Ejemplos prácticos
Chat básico: servidor nc -l -p 4444, cliente nc host 4444


Transferir archivo: nc -l -p 9000 > recibido.iso ⇆ nc host 9000 < imagen.iso


Escaneo de puertos: nc -zv 192.168.1.20 20-25



Comando s s_client (manpage)
Permite probar conexiones TLS/SSL.

Operando principal -connect

openssl s_client -connect ejemplo.com:443

Muestra el handshake, el certificado presentado y, opcionalmente, permite enviar comandos HTTP manualmente.

Otras opciones útiles: -servername (SNI), -showcerts, -tls1_3 para forzar versión.


Comando ss (manpage)
Inspecciona sockets de red (reemplazo moderno de netstat).

Para ver puertos abiertos y servicios:

ss -tlupn

-t TCP · -u UDP · -l listening · -p mostrar proceso · -n sin resolver nombres.
